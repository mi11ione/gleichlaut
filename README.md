# Gleichlaut (Hack Apertus, Track 2B)

The project lives in [`track_2b/`](track_2b/): start with [`track_2b/README.md`](track_2b/README.md), then
[`track_2b/technical_report.md`](track_2b/technical_report.md). Judges run `make run` from inside `track_2b/`.

Guarded German→French/Italian drafting of amendments to Swiss drug-reimbursement conditions with Apertus: numbers reach
the model only as slot codes, frozen deterministic guards decide what is ready, and every number in the documentation is
traceable to a results file (`track_2b/claims.tsv`).
