# Submission form: notes field (≤ 5000 characters; jurors read it)

Start with `make run` in track_2b/ (Docker, CPU; it runs with --network none unless LLM_BASE_URL is set). It verifies the sha256 of the frozen code, guards and test items, re-executes our recorded Apertus 70B run end-to-end from the recorded responses (all 285 model requests rebuilt byte-for-byte and found by payload hash), re-scores every run against eval/results, emits and validates XLIFF 2.1 and FHIR R5, and builds a review page (out/ui/index.html). With LLM_BASE_URL set it also drafts 5 federal-statute paragraphs live.

Problem, evidenced: BAG publishes the reimbursement conditions of the Spezialitätenliste in German, French and Italian under one identifier (9.08 million insured). We found 5 independent divergences in current conditions and verified each by reading the German, French and Italian texts side by side (Nemluvio every 8 weeks vs "ogni 4 settimane"; Diaphin 6% vs 12%; a French-only 62.5 kg condition in 3 etanercept products; Cresemba; Dupixent). All 5 are numbers. In Gleichlaut numbers reach the model only as slot codes and code writes them back.

Headline (pre-registered; guards and resources hashed before any output existed): on a fresh held-out set of 166 FR/IT items from 2025 SL changes (154 in unseen edit families), Apertus 70B drafts equal the official text 17.5% of the time vs 6.0% for rules only (+11.4, 95% CI [4.8, 18.7]); 39.8% of items come out ready, with 0 meaning errors, stale changes or untranslated German among them (95% upper bound 2.3% of items, 5.5% of ready drafts); a blind second Claude annotator also found none. A pre-registered rerun with a different seed passes the same rule (exact +12.0, 58.4% flagged, 2 of 166 ready drafts with a Germanised compound). CHF 0.0024 per item at a Swiss provider's price.

Size, measured on the same items: on SL limitations the 8B flags 85.0% of drafts (cap 70%), so SL uses the 70B on a user-controlled endpoint that must pass `make certify`. On federal statutes the 70B is not better than the 8B (exact 48.3% vs 50.0%; 2 vs 0 real errors among drafts marked ready), so statutes use the 8B on CPU, air-gapped.

What did not hold, all disclosed: our first out-of-sample 70B run FAILED the same pass rule (4.1% untranslated German); on statutes neither size passes our own rule (German job titles like EFZ left untranslated), so every statute draft goes to a translator; our backtest found no translation lag at BAG (French and Italian updated in the same month for 208 of 216 changes), so the value is review effort and number safety inside each amendment, not speed; the 5 divergences predate our data window; about two thirds of flags are wasted review; no direction-flip guard; translator minutes saved are not yet measured.

Where Apertus fell short (docs/failure-modes.md): free translation flips obligations (deve → dovrebbe); neither size obeys "edit only this span"; neither can judge equivalence (0 of 9 known divergences).
